# The synthetic eval corpus — CC0 dedication

The eval corpus generated by `AshEvidence.EvalSets.SyntheticCorpus` —
every fabricated document, every eval item, and every regeneration of
them from the fixed seed — is **dedicated to the public domain under
the Creative Commons CC0 1.0 Universal licence
([SPDX: CC0-1.0](https://spdx.org/licenses/CC0-1.0.html))**.

Concretely:

- The content is fabricated: invented vendor and clinic names
  ("SYNTH CLINIC GROUP", "SYNTH VENDOR", "SYNTH SIGNATORY"), numbered
  agreement references ("SYNTH-AG-00001"), synthetic calendar dates,
  and parameterised compliance propositions from a fixed template bank.
- **No real document, no copyrighted text, and no customer data enters
  the corpus** — the generator cannot: it synthesises from its own
  vocabulary and nothing else.
- Every eval item carries the dedication as metadata
  (`license: "CC0-1.0"`, `source: "ash_evidence/synthetic-corpus/1"`),
  so provenance travels with the data wherever the corpus lands.
- Regeneration is deterministic (fixed seed, byte-stable), so the
  dedicated work is exactly reproducible by anyone running the
  generator.

Note: this dedication applies to the GENERATED CORPUS DATA. The
generator itself (like all of this repository's source) is MIT —
see LICENSES/MIT.txt and REUSE.toml.
